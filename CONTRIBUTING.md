# Contributing

This repository holds published output only. A private pipeline builds the daily brief and pushes
the rendered pages here, and GitHub Pages serves them. A pull request that edits a brief would be
overwritten by the next publish.

- **A correction to a brief:** use the corrections link in the footer of that brief.
- **A problem with the site itself** (a broken page, link, feed or layout): open an issue.

The briefs cover institutions and public records, not private individuals. Please keep it that way
in issues too, and do not post anyone's personal details.

Security problems are reported privately; see [SECURITY.md](SECURITY.md). Everyone taking part
follows the [code of conduct](CODE_OF_CONDUCT.md).
