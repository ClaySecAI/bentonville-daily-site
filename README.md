# bentonvilledaily.com

Published output only. This repo is generated: a private pipeline builds the daily
brief and pushes the rendered HTML here, which GitHub Pages serves.

Briefs cover Bentonville-area institutions and public records — council and
commission decisions, permits and filings, public works, weather alerts. They do
not report on private individuals. Summaries are original wording; every item
links to its source.

Corrections: see the footer of any brief.
